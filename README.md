# Bank Management System

A simple console-based Bank Management System implemented in C. 

## Features
- **Account Creation**: Adds new customer account information (Account Number, Name, Initial Balance).
- **File Storage**: Saves account records permanently into a local `account.txt` text file.

## How to Run
1. Open `main.c` in any standard C compiler or IDE (e.g., Code::Blocks, Dev-C++, Visual Studio Code).
2. Compile and run the program.
